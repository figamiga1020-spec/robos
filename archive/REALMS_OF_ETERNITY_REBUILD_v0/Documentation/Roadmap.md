# REALMS OF ETERNITY REBUILD — Roadmap

**World:** Aydra  
**Capital:** Aurenholm  
**First Region:** Eldoria  
**Project:** REALMS_OF_ETERNITY_REBUILD  

## Design Pillars
- Continuous open world (NO region portals)
- Quality over quantity
- Playable vertical slice first
- Server-authoritative systems

## Vertical Slice Goal (Must Be Playable End-to-End)
Character Create → Aurenholm → Walk to Eldoria → Quests → Combat → Dungeon → Forest Guardian → Rewards → Save → Reload
